MODULE 1Mathematical logic

Short theory

Logic in one page

Connectives you must translate correctly

p→q ≡ ¬p∨q ≡ ¬q→¬p (contrapositive)
p↔q ≡ (p→q)∧(q→p)
"p only if q"            p→q
"p is sufficient for q"  p→q
"q is necessary for p"   p→q
"p unless q"             ¬q→p
"not p unless q"         p→q

Laws (name them in every step)

De Morgan  ¬(p∧q) ≡ ¬p∨¬q   ¬(p∨q) ≡ ¬p∧¬q
Distributive  p∨(q∧r) ≡ (p∨q)∧(p∨r)
Absorption  p∨(p∧q) ≡ p    p∧(p∨q) ≡ p
Negation  p∨¬p ≡ T   p∧¬p ≡ F
Identity  p∨F ≡ p   p∧T ≡ p   Domination  p∨T ≡ T   p∧F ≡ F

Classifying a formula

Tautology: always T. Contradiction: always F. Contingency: both. To prove contingency, show one T assignment and one F assignment.

Normal forms

Minterm: AND of every variable or its negation. Maxterm: OR of every variable or its negation. PDNF = OR of minterms of the T rows. PCNF = AND of maxterms of the F rows (signs flipped). #minterms + #maxterms = 2ⁿ.

Inference

MP  p, p→q ⇒ q          MT  ¬q, p→q ⇒ ¬p
HS  p→q, q→r ⇒ p→r      DS  p∨q, ¬p ⇒ q
Simplification p∧q ⇒ p  Addition p ⇒ p∨q
Rule P: bring in a premise   Rule T: use a law/implication
Rule CP: to get A→B, assume A and derive B
Inconsistent premises: derive X∧¬X ≡ F

Predicates and quantifiers

"All A are B"   ∀x(A(x) → B(x))
"Some A are B"  ∃x(A(x) ∧ B(x))
¬∀x P(x) ≡ ∃x ¬P(x)    ¬∃x P(x) ≡ ∀x ¬P(x)
US: ∀xP(x) ⇒ P(c)       ES: ∃xP(x) ⇒ P(c) for a NEW c
UG: P(y), y arbitrary ⇒ ∀xP(x)   EG: P(c) ⇒ ∃xP(x)
Order: do ES first, then US with the same c.

Type 1Classify a formula without a truth table

C1 Q5(a)5 marks

Without a truth table, simplify φ = [(p→q)∧(q→r)] ∨ [(q→p)∧(r→q)] and classify it.

1

Remove arrows with p→q ≡ ¬p∨q: φ ≡ [(¬p∨q)∧(¬q∨r)] ∨ [(¬q∨p)∧(¬r∨q)].

2

Name the four brackets X₁ = ¬p∨q, X₂ = ¬q∨r, Y₁ = ¬q∨p, Y₂ = ¬r∨q. The shape is (X₁∧X₂)∨(Y₁∧Y₂). Distributing twice gives (X₁∨Y₁)∧(X₁∨Y₂)∧(X₂∨Y₁)∧(X₂∨Y₂).

3

Work out each piece:

X₁∨Y₁ = ¬p∨q∨¬q∨p = (p∨¬p)∨(q∨¬q) = T
X₁∨Y₂ = ¬p∨q∨¬r∨q = ¬p∨q∨¬r
X₂∨Y₁ = ¬q∨r∨¬q∨p = p∨¬q∨r
X₂∨Y₂ = ¬q∨r∨¬r∨q = T
4

T∧A ≡ A, so φ ≡ (¬p∨q∨¬r) ∧ (p∨¬q∨r).

5

Test: p = q = r = T makes both brackets T, so φ = T. p = T, q = F, r = T makes the first bracket F∨F∨F = F, so φ = F.

φ ≡ (¬p∨q∨¬r)∧(p∨¬q∨r): a contingency (false only for p,q,r = T,F,T and F,T,F).

Premises: “If the keynote speaker cancelled or the venue booking failed, then the conference will be rescheduled and the proceedings will be delayed.” “If the conference is rescheduled, then registration fees are refunded.” “Registration fees were not refunded.” Conclusion: “The keynote speaker did not cancel.”

Type 6“Can we conclude…? If not, what is correct?”

C1 Q1(b)5 marks

(i) If he has dinner, then he does not drink tea. (ii) He eats fruits only if he drinks tea. (iii) He does not take juice unless he eats fruits. Can we conclude that he takes juice whenever he has dinner? If not, what is the correct conclusion?

1

Symbols: D: has dinner; T: drinks tea; F: eats fruits; J: takes juice.

2

Translate carefully. (i) D→¬T. (ii) “F only if T” means F→T. (iii) “not J unless F” means “if not F then not J”: ¬F→¬J, which is equivalent to J→F.

3

Proposed conclusion: D→J. Derive what actually follows:

1. D → ¬T          Rule P
2. F → T           Rule P
3. ¬T → ¬F         Rule T, 2  Contrapositive
4. D → ¬F          Rule T, 1,3 Hypothetical syllogism
5. ¬F → ¬J         Rule P (premise iii)
6. D → ¬J          Rule T, 4,5 Hypothetical syllogism
4

Show D→J does not follow: take D = T, T = F, F = F, J = F. Premises: D→¬T = T, F→T = T, ¬F→¬J = T. All true. But D→J = T→F = F. So the conclusion can be false while all premises are true.

No. The correct conclusion is D → ¬J: “If he has dinner, he does not take juice.”

MODULE 2Algebraic structures and group codes

Short theory

Groups and codes in one page

Ladder of structures

Algebraic system: set + operation (closure)
Semigroup = closure + associative
Monoid    = semigroup + identity
Group     = monoid + every element has an inverse
Abelian   = group + commutative

Finite set: draw the Cayley table. Closure = all entries in the set; identity = row copying the header; inverse = where e appears in each row; abelian = table symmetric.

Subgroups, cosets, orders

H ≤ G (one-step test): H ≠ ∅ and a, b ∈ H ⇒ ab⁻¹ ∈ H (additive: a − b ∈ H). Left coset aH = {ah : h ∈ H}; cosets are equal or disjoint and all have size |H|. Lagrange: |G| = (number of cosets)·|H|, so |H| divides |G|. Order of a = least n with aⁿ = e. Union of subgroups is a subgroup only if one contains the other.

Homomorphism

f: (G,∗) → (G′,·) with f(a∗b) = f(a)·f(b) for all a, b. Consequences: f(e) = e′, f(a⁻¹) = f(a)⁻¹. To disprove, one failing pair is enough.

Group codes

Encoding e: Bᵐ → Bⁿ, codeword = x·G (mod 2)
G = [I_m | A]   ⇔   H = [Aᵀ | I_(n−m)]
Syndrome s = H·rᵀ (mod 2)
  s = 0            → r is a codeword
  s = column j     → flip bit j
  s = no column    → ≥ 2 errors (use coset leader)
Min distance d (= min weight of non-zero codeword):
  detects d−1 errors, corrects ⌊(d−1)/2⌋
Corrects all single errors ⇔ columns of H non-zero and distinct

Decoding table: one row per syndrome; coset leader = lightest error with that syndrome. Two leaders of equal weight ⇒ not uniquely decodable.

Type 1Operation on a set: which axioms hold?

A23 Q3(a)5 marks

On G = {(α,β) : α,β ∈ ℚ, α ≠ 0} define (α,β)∗(μ,δ) = (αμ, αδ+β). Prove (G,∗) is a semigroup; is ∗ commutative? Find the identity and inverses.

1

Closure: αμ ≠ 0 when α, μ ≠ 0, and αδ+β ∈ ℚ. So the result is in G.

2

Associativity:

[(a,b)∗(c,d)]∗(e,f) = (ac, ad+b)∗(e,f) = (ace, ac·f + ad + b)
(a,b)∗[(c,d)∗(e,f)] = (a,b)∗(ce, cf+d) = (ace, a(cf+d) + b) = (ace, acf + ad + b)

Equal, so ∗ is associative and (G,∗) is a semigroup.

3

Commutative? (1,2)∗(2,0) = (2, 1·0+2) = (2,2) while (2,0)∗(1,2) = (2, 2·2+0) = (2,4). Not commutative.

4

Identity (e₁,e₂): (a,b)∗(e₁,e₂) = (ae₁, ae₂+b) = (a,b) ⇒ e₁ = 1, e₂ = 0. Check from the left: (1,0)∗(a,b) = (a, b+0) = (a,b) ✓.

5

Inverse of (a,b): (a,b)∗(c,d) = (ac, ad+b) = (1,0) ⇒ c = 1/a, d = −b/a. Check: (1/a, −b/a)∗(a,b) = (1, b/a − b/a) = (1,0) ✓.

Semigroup (in fact a group), not commutative; identity (1,0); (a,b)⁻¹ = (1/a, −b/a).

Type 3Direct product of groups

N24 Q310 marks

(A,△) and (B,∗) are abelian groups. On A×B define (a₁,b₁)□(a₂,b₂) = (a₁△a₂, b₁∗b₂). Is (A×B,□) an abelian group?

Type 4Union of subgroups, cosets, disprove a homomorphism

C1 Q3 (a)(b)(c)3 + 4 + 3 marks

(a) Prove or disprove: the union of two subgroups of G is a subgroup. (b) G = (ℤ,+), H = 3ℤ; find the cosets of H. (c) Is f: (ℤ₄,+₄) → (ℤ₁₀,+₁₀), f(x) = 2x, a homomorphism?

a

False in general. Counterexample in (ℤ,+): H₁ = 2ℤ and H₂ = 3ℤ are subgroups. 2 ∈ H₁∪H₂ and 3 ∈ H₁∪H₂, but 2+3 = 5 is neither even nor a multiple of 3, so 5 ∉ H₁∪H₂. Not closed ⇒ not a subgroup. (It is a subgroup only when one subgroup contains the other.)

b

Cosets a + 3ℤ = {a + 3t : t ∈ ℤ}. Every integer leaves remainder 0, 1 or 2 on division by 3, so there are exactly three:

0 + 3ℤ = {…, −6, −3, 0, 3, 6, …}
1 + 3ℤ = {…, −5, −2, 1, 4, 7, …}
2 + 3ℤ = {…, −4, −1, 2, 5, 8, …}
3 + 3ℤ = 0 + 3ℤ, 4 + 3ℤ = 1 + 3ℤ, …   They are disjoint and cover ℤ.
c

Need f(a +₄ b) = f(a) +₁₀ f(b) for all a, b. Try a = 3, b = 1: f(3 +₄ 1) = f(0) = 0, while f(3) +₁₀ f(1) = 6 + 2 = 8. 0 ≠ 8.

(a) Disproved by 2ℤ ∪ 3ℤ. (b) 3ℤ, 1+3ℤ, 2+3ℤ. (c) Not a homomorphism.

Type 5Prove a subgroup and a homomorphism (matrices)

C2 Q3 (a)(b)7 + 3 marks

(a) Prove H = {A ∈ GL(2,ℝ) : det A = 1} is a subgroup of GL(2,ℝ) under matrix multiplication. (b) f: (ℝ,+) → GL(2,ℝ), f(x) = [[eˣ, 0],[0, e⁻ˣ]]. Prove f is a homomorphism.

1

Non-empty: I = [[1,0],[0,1]] has det 1, so I ∈ H.

2

Closure: A, B ∈ H ⇒ det(AB) = det A · det B = 1·1 = 1 ⇒ AB ∈ H.

3

Inverse: A ∈ H ⇒ det A = 1 ≠ 0 so A⁻¹ exists, and det(A⁻¹) = 1/det A = 1 ⇒ A⁻¹ ∈ H.

4

Associativity is inherited from matrix multiplication. Hence H is a subgroup. (One-step test version: det(AB⁻¹) = 1/1 = 1.)

5

(b) f(x) has det eˣ·e⁻ˣ = 1 ≠ 0, so f(x) ∈ GL(2,ℝ). For x, y ∈ ℝ:

f(x)·f(y) = [[eˣ,0],[0,e⁻ˣ]]·[[eʸ,0],[0,e⁻ʸ]] = [[eˣeʸ, 0],[0, e⁻ˣe⁻ʸ]]
          = [[e^(x+y), 0],[0, e^−(x+y)]] = f(x+y)

H (= SL(2,ℝ)) is a subgroup; f(x+y) = f(x)f(y), so f is a homomorphism.

MODULE 4Posets, lattices and Boolean algebra

Short theory

Lattices and Boolean algebra in one page

Posets and Hasse diagrams

Partial order = reflexive + antisymmetric + transitive. Hasse diagram: draw a below b only when b covers a (a < b, nothing in between); no loops, no transitive edges, no arrows.

Maximal: nothing above. Greatest: above everything (unique). Upper bound of S: above every element of S; lub = least upper bound. Lower bound and glb dually.

Lattices

Lattice: every pair has a lub (∨, join) and glb (∧, meet). In Dₙ (divisors of n): a ∨ b = lcm, a ∧ b = gcd. Bounded: has 0 and 1. Every finite lattice is complete and bounded. Complemented: every x has x′ with x ∧ x′ = 0, x ∨ x′ = 1. Distributive ⇔ no sublattice M₃ (diamond) or N₅ (pentagon); then complements are unique. Dₙ is a Boolean algebra ⇔ n is square-free.

Boolean laws

x + x′ = 1   x·x′ = 0   x + x = x   x·x = x
x + 1 = 1    x·0 = 0
Absorption  x + xy = x     x(x + y) = x
            x + x′y = x + y
De Morgan   (x + y)′ = x′y′    (xy)′ = x′ + y′
Consensus   xy + x′z + yz = xy + x′z

SOP, POS, K-map

Canonical SOP = sum of minterms where f = 1; canonical POS = product of maxterms where f = 0. K-map: Gray-code order (00, 01, 11, 10); group 1s in rectangles of 1, 2, 4, 8 (wrap around edges allowed), as large as possible; each group gives one product term.

Connected graph: Euler circuit ⇔ every degree even; Euler trail (not circuit) ⇔ exactly 2 odd vertices (start at one, end at the other). Hamilton cycle: no simple test; Dirac: deg(v) ≥ n/2 for all v ⇒ Hamiltonian. A cut vertex ⇒ no Hamilton cycle.

Source 0, others ∞. Repeat: box the smallest open label; for each neighbour w, label(w) = min(label(w), boxed + weight), note the predecessor. Stop when the target is boxed; trace predecessors back.

Short theory

Trees in one page

Tree facts

Tree: connected and acyclic. n vertices ⇒ n − 1 edges; exactly one path between any two vertices; every edge is a bridge; at least two leaves (n ≥ 2).

Eccentricity e(v) = max distance from v. Radius = min e(v), diameter = max e(v), centre = vertices with e(v) = radius. A tree has 1 or 2 centres (find them by deleting leaves repeatedly).

Traversals

Preorder   Root, Left, Right
Inorder    Left, Root, Right   (BST → sorted order)
Postorder  Left, Right, Root
Build from inorder + postorder: last of post = root,
split inorder at the root, recurse on both sides.

Spanning trees and MST

Spanning tree: n − 1 edges of G reaching every vertex, no cycle. Kruskal: sort edges ascending; accept unless it forms a cycle; stop at n − 1. Prim: grow from one vertex, always adding the cheapest edge leaving the tree. Both give the minimum total; equal weights may give different trees with the same total.

Fundamental circuits and cut-sets

Branches = edges of T, chords = the rest. Fundamental circuit of a chord = chord + tree path between its ends; there are e − n + 1 of them. Fundamental cut-set of a branch = remove it from T, then list every edge of G joining the two parts; there are n − 1. A branch lies in its cut-set together with exactly the chords whose circuits contain it.

More tree facts (from your notes)

These four statements are equivalent for a graph G on n vertices: G is a tree; there is exactly one simple path between every pair of vertices; G is connected with n − 1 edges; G is acyclic with n − 1 edges.

Full binary tree (every internal vertex has exactly 2 children): n is odd, number of leaves = (n + 1)/2, and minimum height of an n-vertex binary tree = ⌈log₂(n + 1) − 1⌉.

Rank, nullity, cut-set properties

For G with n vertices and m edges and spanning tree T: branches = n − 1 = rank; chords = m − n + 1 = nullity (cyclomatic number).

  1. Every edge of a tree is a cut-set.
  2. Every cut-set of G contains at least one branch of every spanning tree.
  3. Every chord defines a unique fundamental circuit.
  4. Every branch defines a unique fundamental cut-set.

Short theory

Colouring and matching in one page

Colouring

Proper colouring: adjacent vertices get different colours. χ(G) = fewest colours. Bounds: clique size ≤ χ ≤ Δ + 1. χ ≤ 2 ⇔ bipartite; odd cycle ⇒ χ ≥ 3; planar ⇒ χ ≤ 4 (four colour theorem). A chromatic partition = the colour classes (each an independent set).

Welsh–Powell: order vertices by decreasing degree; give colour 1 to the first and to every later vertex not adjacent to one already coloured 1; repeat with colour 2, …

Chromatic polynomial P(G,k)

Kₙ: k(k−1)…(k−n+1)     tree on n: k(k−1)ⁿ⁻¹
Cₙ: (k−1)ⁿ + (−1)ⁿ(k−1)  pendant vertex: × (k−1)
Glued on one vertex: P₁P₂/k   on one edge: P₁P₂/(k(k−1))
Deletion–contraction: P(G) = P(G − e) − P(G / e)
Non-adjacent u,v:     P(G) = P(G + uv) + P(G, u=v merged)
Properties: degree n, leading coeff 1, coeff of kⁿ⁻¹ = −|E|,
signs alternate, constant term 0.  χ = least k with P(k) > 0.

Matching and covering

Matching: edges with no shared vertex
  maximal = can't add an edge; maximum = largest size (β₁)
  perfect = covers every vertex
